# План тестирования (Test Plan)

**Проект:** DataBridge — Конвертер и валидатор данных  
**Версия документа:** 1.0  
**Цель:** Обеспечить 100% проверку соответствия системы функциональным и нефункциональным требованиям технического задания.

---

## 1. Стратегия тестирования

Тестирование разделено на три уровня:
1. **Модульное тестирование (Unit Tests):** Изолированная проверка функций валидации, трансформаций, компонентов чтения и записи.
2. **Интеграционное тестирование (Integration Tests):** Проверка сквозного конвейера обработки данных (чтение → валидация → трансформация → запись → отчёт).
3. **Системное/CLI тестирование (System Tests):** Проверка команд CLI, кодов возврата, генерации файлов и обработки пользовательских ошибок.

---
