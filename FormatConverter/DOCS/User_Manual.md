# Руководство пользователя (User Manual)

**Программа:** DataBridge (Конвертер и валидатор данных)  
**Версия:** 1.0.0  
**Назначение:** Чтение, валидация по схеме, очистка/трансформация и конвертация табличных данных между форматами CSV, JSON, XML и Excel (.xlsx).

---

## 1. Системные требования и установка

### 1.1. Требования к окружению
- Операционная система: Windows 10/11, Linux, macOS.
- Среда выполнения: Python версии **3.8 или выше** (рекомендуется Python 3.12).

### 1.2. Установка зависимостей
В корневой папке проекта выполните установку библиотек:
```bash
pip install -r requirements.txt
```

### 1.3. Регистрация глобальной команды `databridge`
Чтобы утилиту можно было вызывать из любой папки командой `databridge`, установите проект в режиме разработки:
```bash
pip install -e .
```

*Примечание:* Если вы не хотите устанавливать утилиту глобально, вы можете запускать её через файл в корне:
```bash
python FormatConverter.py <команда> [параметры]
```
или как модуль:
```bash
python -m databridge <команда> [параметры]
```

## 2. Команды интерфейса командной строки (CLI)

### 2.1. Команда `convert`
Основная команда для конвертации файла в другой формат с опциональной валидацией, фильтрацией некорректных записей и маппингом полей.

**Синтаксис:**
```bash
databridge convert <входной_файл> [параметры]
```

**Доступные параметры:**
| Параметр | Краткая форма | Описание | Обязательный |
|---|---|---|---|
| `<входной_файл>` | &mdash; | Путь к исходному файлу данных (`.csv`, `.json`, `.xml`, `.xlsx`) | **Да** |
| `--to` | &mdash; | Целевой формат конвертации: `json`, `csv`, `xml`, `excel` | Да (если не задан `--output`) |
| `--output` | `-o` | Путь к результирующему файлу (расширение определяет формат) | Да (если не задан `--to`) |
| `--config` | `-c` | Путь к файлу правил валидации (`schema.yaml` или `schema.json`) | Нет |
| `--errors` | `-e` | Путь для сохранения отсеянных ошибочных строк (по умолч.: `errors.csv`) | Нет |
| `--report` | `-r` | Путь для сохранения визуального HTML-отчёта (`report.html`) | Нет |
| `--delimiter` | &mdash; | Явный разделитель колонок для CSV (например, `,` или `;`) | Нет |
| `--sheet` | &mdash; | Имя листа в документе Excel (по умолчанию: активный лист) | Нет |

**Примеры запуска:**
```bash
# 1. Простая конвертация CSV в JSON без схемы:
databridge convert table.csv --to json --output table.json

# 2. Полный цикл: чтение CSV, валидация по схеме, фильтрация ошибок, сохранение JSON и HTML-отчёта:
databridge convert samples/invalid.csv --to json --config samples/schema.yaml --output output.json --report report.html

# 3. Конвертация XML в электронную таблицу Excel:
databridge convert samples/input.xml --to excel --output report.xlsx
```

### 2.2. Команда `validate`
Проверяет файл на соответствие правилам схемы без генерации конвертированного файла данных. Удобно для проверки перед импортом в базу данных или в скриптах CI/CD.

**Синтаксис:**
```bash
databridge validate <входной_файл> --config <файл_схемы> [параметры]
```

**Доступные параметры:**
| Параметр | Краткая форма | Описание | Обязательный |
|---|---|---|---|
| `<входной_файл>` | &mdash; | Путь к файлу данных для валидации | **Да** |
| `--config` | `-c` | Путь к схеме правил (`schema.yaml` или `schema.json`) | **Да** |
| `--report` | `-r` | Путь для сохранения HTML-отчёта об ошибках | Нет |
| `--errors` | `-e` | Файл для записи некорректных строк (по умолчанию: `errors.csv`) | Нет |

**Пример:**
```bash
databridge validate samples/input.json --config samples/schema.json --report report.html
```

---

### 2.3. Команда `stats`
Выполняет быстрый статистический анализ структуры и качества файла: определяет количество записей, заполненность колонок, количество уникальных значений и вычисляет предполагаемый тип данных.

**Синтаксис:**
```bash
databridge stats <входной_файл>
```

**Пример вывода:**
```text
=================================================================
СТАТИСТИКА ФАЙЛА: samples/valid.csv
=================================================================
Размер файла:        0.41 КБ
Всего записей:       10
Количество колонок:  5
-----------------------------------------------------------------
Колонка            | Тип      | Заполнено  | Пустых   | Уникальных
-----------------------------------------------------------------
id                 | integer  | 10/10      | 0        | 10        
name               | string   | 10/10      | 0        | 10        
email              | string   | 10/10      | 0        | 10        
age                | integer  | 10/10      | 0        | 10        
birth_date         | date     | 10/10      | 0        | 10        
=================================================================
```

## 3. Коды возврата (Exit Codes)

Для интеграции в автоматические сценарии (Bash, PowerShell, GitHub Actions) утилита возвращает стандартные коды завершения:
- **`0`**: Операция успешно выполнена (при `validate` — ошибок валидации не обнаружено).
- **`1`**: Обнаружены ошибки валидации данных либо сбой доступа к файлу/синтаксическая ошибка.

## 4. Часто задаваемые вопросы и устранение неполадок

- **Вопрос:** *Что делать, если файл CSV в русской кодировке CP1251 (Windows-1251)?*  
  **Ответ:** DataBridge автоматически перебирает кодировки `utf-8`, `utf-8-sig`, `cp1251`, `latin-1`. Никаких дополнительных параметров указывать не требуется.
- **Вопрос:** *Где найти строки, которые не прошли валидацию?*  
  **Ответ:** Все забракованные строки автоматически записываются в файл `errors.csv` (или файл, указанный через `--errors`). В первой колонке записан исходный номер строки, во второй — причина отказа.
- **Вопрос:** *Как открыть HTML-отчёт?*  
  **Ответ:** Сгенерированный файл `report.html` открывается в любом современном веб-браузере (Chrome, Edge, Firefox, Safari). Интернет-соединение не требуется.
